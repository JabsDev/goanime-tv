# Play Store Listing Assets — GoAnime TV v1.0

## Screenshots

- Format: PNG or JPEG
- Dimensions: 1920x1080 pixels (landscape, 16:9) — required for Android TV
- Count: 2-8 screenshots
- Content guidance:
  - Screenshot 1: Home screen with catalog rows (trending, seasonal, continue watching)
  - Screenshot 2: Search screen with keyboard overlay
  - Screenshot 3: Anime detail screen with episode grid
  - Screenshot 4: Video player with playback controls
  - Screenshot 5: Profile screen (history, favorites, AniList login)
  - Additional: Show multi-source selector, quality picker, AniList enrichment
- Naming convention: `screenshot_01.png`, `screenshot_02.png`, ... (saved in `assets/store/`)
- Warning: Do not include copyrighted artwork as primary screenshot content. Use app UI screens showing the app in use. Avoid any content that could trigger copyright takedown.

## TV Banner

- Format: PNG or JPEG
- Dimensions: 1280x720 pixels
- Content: App logo + tagline on dark background
- File: `tv_banner.png` (saved in `assets/store/`)

## Feature Graphic

- Format: PNG or JPEG
- Dimensions: 1024x500 pixels
- Content: App branding image for Play Store listing
- File: `feature_graphic.png` (saved in `assets/store/`)

## App Icon

- Format: PNG
- Dimensions: 512x512 pixels (Play Store), 192x192 pixels (Android TV)
- Already exists in `android/app/src/main/res/mipmap-*/` — verify they are TV-optimized (no unnecessary white backgrounds)

> Create these images using your preferred tool (Figma, Photoshop, GIMP, or automated screenshot capture from emulator). These are binary assets that cannot be generated by code alone.
