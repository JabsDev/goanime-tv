<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Developer machine → keystore | Keystore file lives in android/app/ during local builds. Must not leak to git. |
| Developer machine → CI | Keystore transmitted as base64 GitHub secret. Must not leak in CI logs. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-01 | Information Disclosure | Keystore file committed to git | mitigate | `.gitignore` includes `*.jks` and `key.properties`. CI keeps keystore as base64 GitHub Secret, never checked in. |
| T-05-02 | Tampering | build_android.sh downloads | mitigate | Script is version-controlled in the repo. CI runs the same committed script — no arbitrary downloads. Only existing go.mod dependencies are used. |
| T-05-03 | Spoofing | Release APK signed with wrong key | mitigate | Keystore generated once locally with `keytool -genkey`. Same keystore used locally and in CI. Play App Signing adds additional layer — Google re-signs with their own key after upload. |
| T-05-04 | Information Disclosure | Password leaked in CI logs | mitigate | GitHub Secrets are automatically masked in logs. The CI workflow uses `${{ secrets.* }}` syntax which redacts values. Never `echo` secrets or cat key.properties. |
| T-05-05 | Elevation of Privilege | Compromised CI runner signs malicious APK | accept | Single-developer project. Risk accepted. Play App Signing allows key loss recovery. GitHub-hosted runners are ephemeral — each run gets a clean VM. |
| T-05-06 | Tampering | Package install from `go.mod` dependencies | mitigate | All Go dependencies are pinned to specific versions in `go.mod` (goquery v1.9.2, utls v1.6.6, x/net v0.24.0). CI uses `cache: true` with `cache-dependency-path: go_superflix/go.sum` to verify integrity. |

**ASVS L1 notes:** No user authentication or session management in this phase. Cryptography (V6) applies to keystore generation — `keytool -genkey -keyalg RSA -keysize 2048` meets ASVS 6.2.1 (at least 2048-bit RSA). Play App Signing provides additional key management security.
</threat_model>
