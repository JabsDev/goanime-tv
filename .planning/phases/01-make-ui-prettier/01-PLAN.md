# Phase 01 — Plan: Make UI Prettier

## Goal
Refine the visual design and user experience of GoAnime TV's Flutter UI to be polished, consistent, and TV-remote-friendly.

## Tasks
1. Establish dark theme with color constants (background, surface, primary, accent)
2. Implement focus animations (scale, border, shadow) for TV remote navigation
3. Build home screen with content sections (trending, seasonal, favorites)
4. Build search screen with live results grid
5. Build detail screen with episode grid and quality picker
6. Build video player screen with controls and auto-next
7. Create reusable widget library (cards, buttons, section headers)
