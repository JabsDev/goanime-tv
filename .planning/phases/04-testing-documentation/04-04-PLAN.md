    Add minimal production refactoring to AnimeFireAdapter to support mock-based fixture testing. This is a backward-compatible change — no existing callers need updates.

    **Step 1 — Add field and constructor:**

    Add an `http.Client?` field and constructor parameter. The import `'package:http/http.dart' as http;` already exists at line 6.

    Change:
    ```dart
    class AnimeFireAdapter implements AnimeSourceAdapter {
      AnimeFireAdapter();
    ```
    To:
    ```dart
    class AnimeFireAdapter implements AnimeSourceAdapter {
      final http.Client? _client;

      AnimeFireAdapter({http.Client? client}) : _client = client;
    ```

    **Step 2 — Add private dispatching method:**

    `apiClient` is of type `ApiClient` (not `http.Client`), so a simple getter with `??` won't compile. Add a dispatching method after the constructor:

    ```dart
    Future<http.Response> _httpGet(Uri uri, {Map<String, String>? headers}) {
      if (_client != null) {
        return _client!.get(uri, headers: headers);
      }
      return apiClient.get(uri, headers: headers);
    }
    ```

    **Step 3 — Replace all `apiClient.get(` calls with `_httpGet(`:**

    There are exactly 5 call sites. Replace each one, keeping the same arguments:

    1. `search()` at approx line 43: `res = await _httpGet(...)`
    2. `search()` retry at approx line 47: `res = await _httpGet(...)`
    3. `_fetchEpisodes()` at approx line 185: `final res = await _httpGet(...)`
    4. `_extractFromAnimeFire()` at approx line 227: `final res = await _httpGet(...)`
    5. `_resolveVideoApi()` at approx line 333: `final res = await _httpGet(...)`

    **Step 4 — Verify:**
